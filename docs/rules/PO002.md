# po-requires-module (PO002)

A translation entry lacks its `#. module:` comment.

## What it does

Checks that every entry has the `#. module: <module>` comment Odoo writes
when it exports translations.

## Why is this bad?

Odoo uses the comment to know which module a translation belongs to. Odoo 18
and 19 fail on an entry without it, so the whole file is not loaded (with
the module's `.pot`, which Odoo merges in first).

## Fix safety

Safe: adds `#. module: <module>` to the entry.
