# upgrade-calendar-date-delay (U2011)

A calendar view uses `date_delay`, removed in Odoo 20.0.

Applies to Odoo 20.0 and later.

## What it does

Reports `date_delay` on `<calendar>` views.

## Why is this bad?

Odoo 20.0 removed it: the view fails to validate. Use `date_stop`, if need
be with a computed end date.
