# method-search (C8109)

A field's `search` method is not named `_search_...`.

## What it does

Checks that the method a field names in `search=` starts with `_search_`.

## Why is this bad?

The OCA naming convention makes the purpose of a method clear without
looking up the field that uses it.

## Example

```python
total = fields.Float(search="get_total")
```

Use instead:

```python
total = fields.Float(search="_search_total")
```
