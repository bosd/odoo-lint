# upgrade-js-rpc-service (U1812)

The `rpc` service, removed in Odoo 18.0.

Applies to Odoo 18.0 and later.

## What it does

Reports `useService("rpc")` and `services.rpc`.

## Why is this bad?

Odoo 18.0 removed the `rpc` service; the component fails to start. Import
the function instead:

```js
import { rpc } from "@web/core/network/rpc";
```
